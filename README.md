# mergist

AI-powered merge request summary generator.

## Getting Started

1. **Init** — run `npx mergist init` in your project, select platform and configure settings
2. **Commit** — commit the generated files (`.mergistrc`, CI workflow, and optional standalone script) to your **target branch** (e.g. `main` / `develop`)
3. **Setup CI secrets** — configure `AI_API_KEY` and platform token following the [Setting up secrets](#setting-up-secrets) guide
4. **Create MR/PR** — open a new merge request or pull request targeting that branch
5. **Automated** — CI will run, AI generates the description, and the description gets updated

### Commands

```bash
# Interactive init (scaffold config, CI, templates)
npx mergist init

# Generate description in CI
npx mergist generate --platform gitlab
npx mergist generate --platform github

# Manage config
npx mergist config show
npx mergist config set <key> <value>
```

## Features

- **Multi AI Provider** — OpenAI, DeepSeek, Groq, or Custom (OpenAI-compatible API only)
- **Multi-language** — Indonesian (`id`) or English (`en`)
- **Section templates** — choose which sections to include during init:

  | Section | Description | Filled by |
  |---------|-------------|-----------|
  | `summary` | Brief description of MR/PR | AI |
  | `changes` | Features, fixes, removals | AI |
  | `testing` | Testing checklist | AI |
  | `review` | AI code analysis | AI |
  | `notes` | Developer notes | Human |
  | `references` | Issue/ticket links | Human |
- **Smart merge** — `autoUpdate` only rewrites AI-generated sections, human-filled sections (notes, references) are preserved
- **Standalone script** — optional no-dependency script generated during `init` (for environments without npx)

## Configuration

Config file `.mergistrc` is auto-generated by `npx mergist init`.

### Config keys

| Key | Type | Description |
|-----|------|-------------|
| `platform` | `gitlab` / `github` | Target platform |
| `aiProvider` | `openai` / `deepseek` / `groq` / `custom` | AI provider |
| `lang` | `id` / `en` | Output language |
| `maxDiffChars` | number | Max diff characters sent to AI |
| `autoUpdate` | boolean | Auto-update description on new commits |
| `templates` | array | Active sections |

### CI environment variables

| Variable | Required | Description |
|----------|----------|-------------|
| `AI_API_KEY` | Yes | API key for your AI provider |
| `GITLAB_TOKEN` | GitLab only | GitLab API token (scope: `api`) |
| `GITHUB_TOKEN` | GitHub only | Automatically provided by GitHub Actions |

## Setting up secrets

### GitHub Actions

1. Go to your repository on GitHub
2. Click **Settings** tab
3. In left sidebar, click **Secrets and variables → Actions**
4. Click **New repository secret** button
5. Add the following secrets:

   | Name | Value |
   |------|-------|
   | `AI_API_KEY` | Your AI provider API key (OpenAI / DeepSeek / Groq / Custom) |

6. `GITHUB_TOKEN` is **automatically provided** by GitHub Actions — no setup needed
7. **Ensure workflow has write permission:**
   - Go to **Settings → Actions → General**
   - Scroll to **Workflow permissions**
   - Select **Read and write permissions**
   - Click **Save**

### GitLab CI/CD

1. Go to your project on GitLab
2. Click **Settings → Access Tokens**
3. Click **Add new token**
   - Name: `mergist` *(atau nama lain sesuai keinginan)*
   - Role: `Developer`
   - Scope: check **api**
   - Click **Create project access token**
   - **Copy the token value** — you'll need it in step 7
4. Go to **Settings → CI/CD**
5. In **Runners** section, click **Expand**
   - Go to **Instance** tab
   - Ensure **Turn on instance runners for this project** is checked
6. In **Variables** section, click **Expand**
7. Click **Add variable** and add:

   | Name | Value | Type | Protected | Masked |
   |------|-------|------|-----------|--------|
   | `AI_API_KEY` | Your AI provider API key | Variable | No | Yes |
   | `GITLAB_TOKEN` | Token dari step 3 | Variable | No | Yes |

8. The following variables are **automatically provided** by GitLab CI (no setup needed):
   - `CI_PROJECT_ID`
   - `CI_MERGE_REQUEST_IID`
   - `CI_API_V4_URL` (works for both gitlab.com and self-hosted)
